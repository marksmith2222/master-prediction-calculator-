Save & Restore

Trades save automatically on this device, but Safari and Home Screen apps can keep separate data. A new calculator version may start with 20 sample trades. Always check the trade count before entering trades, and save a JSON backup to iCloud Drive after adding trades.

Restoring replaces the current trades and settings. Export your current backup first.

Use Save Backup JSON to Files, then select Save to Files → iCloud Drive. The file contains all trades and settings. Select Backup Text is an optional manual alternative.

About saving

For reliable Home Screen use, host this HTML at a stable HTTPS website and open that address in Safari, then choose Share → Add to Home Screen. A downloaded HTML file alone is not a hosted iPhone app, and local browser storage is not cloud synchronization.
